# Cybersecurity Projects & Learning Portfolio

## About This Repository

Welcome to my cybersecurity repository!

I'm an engineering student with a growing interest in cybersecurity. I created this repository to document what I learn, experiment with different tools, and share the practical work I do along the way.

My interest in cybersecurity goes beyond understanding concepts from textbooks. I want to explore how systems and networks work, how security vulnerabilities arise, and how different techniques can be used to protect them.

Through this repository, I'll be working on different areas of cybersecurity, including network security, ethical hacking, Linux, cloud security, and Python automation.

I'm still learning, so not everything here will be perfect or advanced. Some implementations might be simple, while others may become more challenging as I improve my skills. The main purpose is to keep learning, try new things, make mistakes, solve problems, and gain real hands-on experience.

## What I'm Focusing On

- **Network Security:** Understanding networks, protocols, configurations, and ways to secure network communication.
- **Ethical Hacking:** Learning how vulnerabilities are identified and tested in controlled environments.
- **Linux Security:** Exploring Linux commands, system administration, permissions, and security configurations.
- **Cloud Security:** Learning how cloud environments work and how to secure services and infrastructure.
- **Python Automation:** Building small tools and scripts to automate security-related tasks.
- **Vulnerability Assessment:** Understanding common vulnerabilities and how to identify and address them.
- **Threat Detection:** Exploring ways to monitor systems and recognize suspicious activities.

## My Learning Goals

As I continue learning, I'll keep adding new experiments, scripts, configurations, and implementations to this repository.
